## 1. Nepal NEB (SEE Class 10 + Class 11/12) — 4.0 GPA scale

### 1.1 Official grade table (Letter Grading Directive 2078, as amended)

The governing document is the Curriculum Development Centre's **Letter Grading Directive, 2078** (4th amendment 2081), applied to Classes 1–12.
The eight-level scale is consistently reproduced across sources citing the directive:

| Percentage | Letter | Grade point | Description |
|---|---|---|---|
| 90 and above | A+ | 4.0 | Outstanding |
| 80 to below 90 | A | 3.6 | Excellent |
| 70 to below 80 | B+ | 3.2 | Very Good |
| 60 to below 70 | B | 2.8 | Good |
| 50 to below 60 | C+ | 2.4 | Satisfactory |
| 40 to below 50 | C | 2.0 | Acceptable |
| 35 to below 40 | D | 1.6 | Basic (minimum pass) |
| Below 35 | NG | none / 0.0 | Not Graded |

- Source for table + directive citation (4th amendment 2081, CDC section 6): https://www.bikrambhujel.com.np/p/neb-gpa-calculator.html
- Same table published for SEE 2081 results "as per Letter Grading Directive 2078 – 3rd Amendment": https://www.ambition.guru/blog/see-result-2081-published
- Same table for SEE 2083 results (Letter Grading Directive 2078 with third modification): https://www.educatenepal.com/news/detail/how-to-check-see-class-10-exam-results-2083-2026-with-marksheet
- Same table for NEB Grade 12 2083 results: https://www.educatenepal.com/news/detail/how-to-check-neb-grade-12-result-2083-2082-with-gradesheet-via-websites-sms-ivr-2026-online
- Same table: https://www.slicejob.com/blog/how-to-check-see-result-2080-via-website-sms-ivr24 ; https://totalgpa.com/blog/how-gpa-is-calculated-in-neb-nepal
- The older nine-level scale (with D+, D, E) is kept ONLY for SEE examinations taken under the pre-National-Curriculum-Framework-2076 syllabus: https://www.bikrambhujel.com.np/p/neb-gpa-calculator.html (UNVERIFIED: exact grade points of legacy D+/D/E from an official source)
- A general news article (My Republica) describes an older nine-grade system (A+…D covering 20–39, E 1–19, N not-graded) — consistent with the legacy scale, not the current directive: https://myrepublica.nagariknetwork.com/news/gpa-system-confusions-galore

### 1.2 CONFLICT — Class 12 low-end bands

One third-party site (thenepal.io) publishes a **nine-band Class 12 table**: D+ = 35–39% = 1.6, D = 20–34% = 1.2 (fail/supplementary), NG = below 20%: https://gpatopercentage.thenepal.io/2026/04/neb-class-12-gpa-to-percentage.html and https://gpatopercentage.thenepal.io/2026/04/nepal-grading-system-guide-2083.html
- The same site contradicts itself on other pages, where it publishes the eight-band D = 35–39 = 1.6 / NG below 35 table: https://gpatopercentage.thenepal.io/p/grading-system-in-nepal-everything-you.html (sections show both "D 1.6 (35–39%)" and, elsewhere, "D+ 35–39 / D 20–34 / NG below 20")
- **No official NEB/CDC source found for the D+/D/NG-below-20 variant.** Decision: use the documented eight-band directive table above; mark the D+ variant UNVERIFIED (conflicting third-party claim).

### 1.3 Pass thresholds

- Minimum pass per subject: **35% in theory AND 40% in internal/practical assessment, separately** — below either threshold the subject is NG: https://www.collegenp.com/news/see-grade-increment-and-supplementary-exam-results-2082 ; https://www.acharyar.com.np/2021/12/new-see-grading-system-2078-nepal.html ; https://www.slicejob.com/blog/how-to-check-see-result-2080-via-website-sms-ivr24
- Numeric minimums (75-mark theory → 27 marks; 50-mark theory → 18; 25-mark internal → 10; 50-mark internal → 20): https://www.collegenp.com/news/see-grade-increment-and-supplementary-exam-results-2082
- Theory and internal marks are converted to grades separately (no cumulative grade if one component fails): https://www.collegenp.com/news/new-grading-system-in-see-examination-must-have-secured-35-marks ; https://www.acharyar.com.np/2021/12/new-see-grading-system-2078-nepal.html
- Applies per subject — each subject must be passed individually (no overall aggregate minimum): https://gpatopercentage.thenepal.io/p/grading-system-in-nepal-everything-you.html (third-party, consistent with all other sources)

### 1.4 GPA computation method

- Within a subject: theory and internal/practical are graded separately; **each grade point is multiplied by its share of the subject's credit hours, summed, and divided by the subject's credit hours**. The resulting average grade point maps back to a final letter grade (e.g. 3.61–4.0 → A+). Sources: Letter Grading System handbook (2079), CDC, via https://www.bikrambhujel.com.np/p/neb-gpa-calculator.html
- Overall GPA: **Σ(Credit Hour × Grade Point) ÷ Total Credit Hours**: https://www.tikka.com.np/2026/09/Neb-Gpa-Calculate.html
- Minor conflict: one source gives a simplified "GPA = sum of grade points ÷ number of subjects": https://vpit.com.np/blog/nepal-government-result-management-guidelines — treated as a simplification, NOT the directive method. Decision: use credit-hour-weighted method (directive-citing source).

### 1.5 SEE vs +2 differences

- Same eight-band scale for both SEE and Class 11/12 per the directive: https://www.bikrambhujel.com.np/p/neb-gpa-calculator.html
- Reported difference: in Class 12, if theory marks fall below 35% of theory full marks the subject is NG **regardless of practical marks**; in SEE this theory-override rule is not applied the same way: https://totalgpa.com/blog/how-gpa-is-calculated-in-neb-nepal (third-party; mark as partially verified)
- NEB's own site (neb.gov.np, accessed 2026-11-04) publishes result notices and the Class 12/SEE assessment frameworks but the grading-scale directive text was not retrievable from its English pages in this pass: https://www.neb.gov.np (site live; grading table not located)

### 1.6 NG / retake rules

- NG in 1–2 subjects → eligible for supplementary "grade increment" exam: https://www.acharyar.com.np/2021/12/new-see-grading-system-2078-nepal.html ; https://www.educatenepal.com/news/detail/how-to-check-see-class-10-exam-results-2083-2026-with-marksheet
- NG in more than 2 subjects → must repeat the full year: https://www.acharyar.com.np/2021/12/new-see-grading-system-2078-nepal.html (third-party)
- No official pass certificate until NG subjects are cleared: https://gpatopercentage.thenepal.io/p/neb-gpa-to-percentage-calculator.html (third-party)

### 1.7 Percentage conversion — UNVERIFIED as official

- **There is no official formula for converting GPA back into a percentage** (grade points come from percentage ranges; a GPA only indicates the range): https://www.bikrambhujel.com.np/p/neb-gpa-calculator.html
- The widely repeated "Percentage = GPA × 25" is a third-party convention, NOT an official NEB formula: https://gpatopercentage.thenepal.io/p/grading-system-in-nepal-everything-you.html . For StudyPilot it must be labeled an **estimate**, not an official conversion.

## 2. NUS (National University of Singapore) — 5.0 GPA scale

Note: NUS renamed "Cumulative Average Point (CAP)" to "Grade Point Average (GPA)", modules to courses, and Modular Credits (MCs) to Units on 1 August 2023; calculation unchanged: https://gpacalc.app/schools/nus/ ; https://aceacademicservice.com.sg/nus-assignment-help/ (third-party summaries of the registrar change)

### 2.1 Official grade-point table

From NUS Faculty of Science freshmen briefing (Office of University Registrar material, science.nus.edu.sg):

| Letter | Grade point | | Letter | Grade point |
|---|---|---|---|---|
| A+ | 5.00 | | C+ | 2.50 |
| A | 5.00 | | C | 2.00 |
| A− | 4.50 | | D+ | 1.50 |
| B+ | 4.00 | | D | 1.00 |
| B | 3.50 | | F | 0.00 |
| B− | 3.00 | | | |

- Table (A/A+ 5.00 … C 2.00, D+ 1.50) plus no-grade-point notations: https://www.science.nus.edu.sg/wp-content/uploads/2026/07/BPharm_Faculty-Freshmen-Briefing-2026_Student-Copy.pdf
- A+ 5.0 / A 5.0 / A− 4.5 confirmed in CDE academic briefing: https://cde.nus.edu.sg/wp-content/uploads/2024/07/CDE-Freshman-Welcome-2024_Academic-Briefing_19Jul2024.pdf
- Same table in official NUS IRO incoming-exchange booklet: https://app.studyabroad.uconn.edu/_customtags/ct_FileRetrieve.cfm?File_ID=050773764F7A027A7103057C711F03737E011B00010A006B7A04000F7777707303050101737A0701
- Law, Dentistry and Medicine run separate grading scales: https://aceacademicservice.com.sg/nus-assignment-help/ (third-party); NUS Law handbook confirms a separate scheme: http://law.nus.edu.sg/nuslawacademy/wp-content/uploads/sites/17/2026/07/GCIPTL-Student-Handbook-AY2627.pdf

### 2.2 GPA computation

- GPA = Σ(course grade point × Units assigned to course) ÷ Σ(Units for all courses used in the numerator): https://fass.nus.edu.sg/socanth/wp-content/uploads/sites/16/2026/07/MA-GSA-Student-Handbook_vJul2026.pdf (NUS Faculty of Arts & Social Sciences student handbook, official)
- Same formula in the NUS IRO exchange booklet: https://app.studyabroad.uconn.edu/_customtags/ct_FileRetrieve.cfm?File_ID=050773764F7A027A7103057C711F03737E011B00010A006B7A04000F7777707303050101737A0701
- All letter grades **including F** are computed in the GPA: https://fass.nus.edu.sg/socanth/wp-content/uploads/sites/16/2026/07/MA-GSA-Student-Handbook_vJul2026.pdf

### 2.3 Excluded from GPA (no grade point)

- **S / U** (Satisfactory/Unsatisfactory): carry no grade point; the letter grade is not shown and not computed towards GPA: https://nus.edu.sg/registrar/academic-information-policies/undergraduate-students/continuation-and-graduation-requirements
- **CS / CU** (Completed Satisfactorily / Completed Unsatisfactorily, for non-gradable courses): listed among no-grade-point notations: https://www.science.nus.edu.sg/wp-content/uploads/2026/07/BPharm_Faculty-Freshmen-Briefing-2026_Student-Copy.pdf
- **EXE** (exempted), **W** (withdrawn), **IC** (incomplete), **IP** (in progress): no-grade-point notations: https://www.science.nus.edu.sg/wp-content/uploads/2026/07/BPharm_Faculty-Freshmen-Briefing-2026_Student-Copy.pdf ; https://app.studyabroad.uconn.edu/_customtags/ct_FileRetrieve.cfm?File_ID=050773764F7A027A7103057C711F03737E011B00010A006B7A04000F7777707303050101737A0701

### 2.4 S/U rules (official registrar page)

Source: https://nus.edu.sg/registrar/academic-information-policies/undergraduate-students/continuation-and-graduation-requirements
- For courses completed **from AY2021/22**: S = grade D or above; U = below D. Before AY2021/22: S = C or above, U = below C.
- Course units count toward the degree only with an S grade; a U earns no units.
- Quota, general: up to **32 Units** for AY2016/17–AY2024/25 cohorts, for courses completed in the first year (first two regular semesters + first-year special term). Of the 32, **20 first-year units** can only be used on first-year courses; any unused balance may be used in later semesters for up to **12 Units**.
- AY2025/26 intake onwards: the 20 time-limited units may be used on courses completed in the **first 2 years** (instead of first year only).
- With 20+ Advanced Placement Credits: up to 20 units (8 time-limited, first year — or first 2 years for AY2025/26+ cohorts).
- With prior university experience recognised toward the degree: up to 12 units, usable any time.
- With a prior university degree: not eligible.
- Applies to Level 1000 courses (with or without prerequisites) and Level 2000 courses without other NUS courses as prerequisites, unless faculties stipulate otherwise.
- Declaration is per-semester exercise after results release; can cover courses from current and preceding semesters of the same academic year; final once the exercise closes.
- Not applicable to Dentistry, Law, Medicine (except Nursing), Yale-NUS College. Law DDP students (with Business/Arts & Social Sciences/Science) get 12 S/U units for non-Law courses counting solely toward the second degree.
- UNVERIFIED: no per-semester cap on S/U units was found in the official rules — do not invent one.

### 2.5 Retakes

- "Students are not permitted to repeat any passed course taken previously": https://fass.nus.edu.sg/socanth/wp-content/uploads/sites/16/2026/07/MA-GSA-Student-Handbook_vJul2026.pdf
- UNVERIFIED as official: whether both the failed original grade and the retake grade count in undergraduate GPA (a third-party source claims both count: https://openeducat.org/gradebook/singapore/reattempt/ — not the registrar).

### 2.6 Continuation / graduation thresholds

- Minimum GPA for graduation: **2.00** (students admitted from AY2016/2017: GPA below 2.00 for two consecutive semesters → dismissal): https://nus.edu.sg/registrar/academic-information-policies/undergraduate-students/continuation-and-graduation-requirements

### 2.7 Honours classification (official)

Source: https://nus.edu.sg/registrar/academic-information-policies/undergraduate-students/continuation-and-graduation-requirements (criteria for students admitted from AY2012/13; honours table refers to 160-unit programmes; Faculty of Law differs):

| Classification | GPA |
|---|---|
| Honours (Highest Distinction) | 4.50 and above |
| Honours (Distinction) | 4.00 – 4.49 |
| Honours (Merit) | 3.50 – 3.99 |
| Honours | 3.00 – 3.49 |
| Pass | 2.00 – 2.99 |
| Bachelor's (120-unit): Pass with Merit | 3.00 and above |
| Bachelor's (120-unit): Pass | 2.00 – 2.99 |

- Note on the official page: "Particular Faculties/Schools may stipulate other requirements" for Highest Distinction.
- Also reproduced in the NUS Science freshmen briefing: https://www.science.nus.edu.sg/wp-content/uploads/2026/07/BPharm_Faculty-Freshmen-Briefing-2026_Student-Copy.pdf

### 2.8 Percentage conversions — UNVERIFIED as official

- NUS publishes **no official marks/percent ranges** per letter grade ("No published marks range"): https://gpacalc.app/schools/nus/ (third-party, consistent with absence on registrar pages)
- Wikipedia's bands (A+ 85–100, A 80–84, A− 75–79…) are NOT from NUS: https://en.wikipedia.org/wiki/Grading_systems_by_country — do not use as official.

## 3. NTU (Nanyang Technological University) — 5.0 CGPA scale

All below from the official **NTU Academic Handbook for Undergraduate Studies, Cohort AY2026-27** (last updated 31 July 2026):
https://www.ntu.edu.sg/media/docs/default-source/office-of-academic-services/academic-handbook-(undergraduate-studies)-ay2026-27v3.pdf?sfvrsn=69b13d12_1

### 3.1 Grade-point table (Handbook §6.2.1)

| Letter | Grade point | | Letter | Grade point |
|---|---|---|---|---|
| A+ | 5.00 | | C+ | 2.50 |
| A | 5.00 | | C | 2.00 |
| A− | 4.50 | | D+ | 1.50 |
| B+ | 4.00 | | D | 1.00 |
| B | 3.50 | | F | 0.00 |
| B− | 3.00 | | | |

- Corroborated in an official NTU exchange document: https://gem.ntu.edu.sg/_customtags/ct_DocumentRetrieve.cfm?token=<redacted> and the NTU SSS freshmen briefing: https://ntu.edu.sg/media/docs/librariesprovider124/default-document-library/2026-acacad_freshmenwelcome-jt.pdf?sfvrsn=a4896b7f_1
- Non-letter notations (§6.2.2): `*` (Pass/Fail only), IP (In Progress), LOA (absent with valid reason), EX (exempted), TC (transfer credits), P (Pass), NR (No Record).

### 3.2 CGPA computation (Handbook §6.2.3)

- CGPA = Σ(Grade Point × AU for each course) ÷ (Total AU attempted in all semesters so far)
- **Includes failed courses**; only letter-graded courses are included.
- Excluded: Pass/Fail-only courses, courses with FGO declared, LOA, EX, IP.
- Handbook worked examples (§6.2.3): F counts at 0.00; FGO P/NR courses excluded from both numerator and denominator.
- YGPA (Year GPA, §6.2.4): same method over Semesters 1+2 of a year; Special Term courses excluded from YGPA.
- CGPA is reflected on transcripts (§6.2.5).

### 3.3 Flexible Grading Option — FGO (Handbook §6.3) — replaced S/U from AY2024/25

- FGO lets students convert eligible courses' grades to **Pass (P)** or **No Record (NR)**, excluded from CGPA (§6.3.2).
- After declaration: letter grades A, B, C, D → **P**; F → **NR**. AU are earned only for P grades (§6.3.3).
- P appears on Degree Audit, RER and Transcript; NR appears only on internal Degree Audit, not on RER/Transcript (§6.3.4).
- All undergraduates eligible EXCEPT LKCMedicine, exchange and non-graduating students (§6.3.5).
- Not applicable to Final Year Projects, Professional Internships/Attachments, courses with academic sanctions (§6.3.6).
- Quota (§6.3.7): **3-year programmes: up to 21 AU**; **4- and 5-year full-time: up to 24 AU**; **part-time: up to 21 AU**; max **12 AU on Major Core, ICC & MPE courses**.
- Declarations submitted in a stipulated window after results release; no late declarations (§6.3.8); **irrevocable** (§6.3.9); quota deducted per course attempt (§6.3.10).
- FGO students must still meet minimum letter-graded AU requirements (§6.3.11; see §3.4: 52 AU for 3-year, 69 AU for 4-year programmes; 18 AU for second major, 9 AU for minor).
- The old S/U option (superseded): S = final letter grade D or better, carries no grade point and no GPA effect; AU earned only with S: https://www.ntu.edu.sg/sbs/admissions/undergraduate/resources-for-students/course-registration-information

### 3.4 Retakes

- Students are NOT allowed to repeat courses they have passed (§6.1.4).
- Grades for ALL attempts in ALL courses appear on the official transcript, except NR after FGO (§6.1.5).
- CGPA covers all courses attempted, including failed courses (§6.2.3) — i.e. a failed attempt's F stays in the CGPA even after a successful retake.
- Restricted repeat available only for failed final-year core courses not offered the following semester (§5.5).

### 3.5 Graduation / standing thresholds

- Minimum CGPA for graduation: **2.00** (§3.5).
- Academic standing (§6.4): Warning if CGPA < 2.00 in a semester; Probation if < 2.00 two consecutive semesters; Termination if < 2.00 three consecutive semesters (or unable to graduate at max candidature).

### 3.6 Degree classification (Handbook §6.6) — officially published

| CGPA range | Classification |
|---|---|
| 4.50 – 5.00 | Honours (Highest Distinction) |
| 4.00 – 4.49 | Honours (Distinction) |
| 3.50 – 3.99 | Honours (Merit) |
| 3.00 – 3.49 | Honours |
| 2.00 – 2.99 | Pass |

- College of Engineering (except Maritime Studies) and College of Computing and Data Science (except Data Science and Artificial Intelligence): Highest Distinction additionally requires **at least a B+ in the Final Year Project**.
- College of Science (except Chinese Medicine): Highest Distinction requires ≥4.50 CGPA **and at least an A− in the FYP**; Distinction requires ≥4.00 CGPA **and at least a Pass in the FYP**.
- School of Humanities / School of Social Sciences: students who opt out of the FYP are ineligible for Highest Distinction or Distinction.
- Same table in the official NTU SSS freshmen briefing: https://ntu.edu.sg/media/docs/librariesprovider124/default-document-library/2026-acacad_freshmenwelcome-jt.pdf?sfvrsn=a4896b7f_1

### 3.7 Percentage conversions — UNVERIFIED as official

- No official NTU percentage bands per letter grade found. Do not use Wikipedia's bands as official.

### 3.8 Other useful official data points

- Dean's List: top 5% of cohort with minimum 4.50 GPA computed on raw grades before FGO, ≥12 AU letter-graded courses (full-time single degree) (§6.7).
- Withdrawal after Add/Drop without sitting assessments → F on transcript (§5.3).
