Backup & storage

Storage usage

Export backup

Downloads one JSON file with everything: notes, files, folders, saved timetables. Keep it somewhere safe · it's the only copy outside this browser.

Import backup

Restore from a backup file. Merge keeps your current data and only adds what's new. Replace deletes everything first · export your current data before doing that.

Keep your data safe. Your study space lives in this browser's storage. It can be lost if you clear browser data, use private/incognito windows, or if the browser evicts it under storage pressure. Export a backup regularly · especially before clearing anything.

Folders

Organize notes and files. Folders can nest inside each other. A folder can only be deleted when it's empty · move its contents out first.
