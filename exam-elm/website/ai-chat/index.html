Encrypted key storage (optional)

By default keys live only in this tab's memory and vanish when you close it. Optionally, store them on this device encrypted with a passphrase you choose. Forget the passphrase and the keys are unrecoverable · there is no reset.

Before you connect a provider, know this

  • Your prompts go directly from this browser to the provider you choose. There is no ExamElm server in between · we never see your prompts or your key.
  • The provider you choose receives everything you send, including any text you paste.
  • Keys are kept in this browser's memory only unless you explicitly opt into passphrase-encrypted storage. An unlocked key could be read by a malicious script, so never paste secrets into chat and keep your browser updated.
  • API billing is separate from ChatGPT, Claude, Gemini or any other consumer subscription · you pay the provider's API rates.
  • Nothing is sent anywhere until you press Send.
